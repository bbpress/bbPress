# bbPress 2.6 maintenance branch

This branch contains the source for bbPress 2.6 maintenance releases. Install
stable packages from the [WordPress.org Plugin Directory](https://wordpress.org/plugins/bbpress/).
The [trunk README](https://bbpress.svn.wordpress.org/trunk/README.md) contains the
project overview and community links.

Canonical Subversion is the source of truth. GitHub is an engineering mirror;
report bugs and attach patches on [bbPress Trac](https://bbpress.trac.wordpress.org/).
Do not merge or push authoritative refs directly to GitHub.

Start with [CONTRIBUTING.md](CONTRIBUTING.md) for this branch's build and testing
instructions. The 2.6 checkout does not contain trunk's Composer or wp-env setup.

Support questions belong in the [support forums](https://bbpress.org/forums/).
Follow [SECURITY.md](SECURITY.md) for private vulnerability reporting.
