# Code of Conduct

bbPress is part of the WordPress open-source project. Participation in bbPress
repositories, Trac, forums, Slack channels, events, and other project spaces is
governed by the
[WordPress Community Code of Conduct](https://make.wordpress.org/handbook/community-code-of-conduct/).

The code asks participants to act with empathy and respect, give and accept
constructive feedback, take responsibility for mistakes, and focus on what is
best for the community. Harassment, personal attacks, publishing private
information without permission, and retaliation are not acceptable.

## Reporting conduct concerns

Report abusive, harassing, or otherwise unacceptable behavior privately to the
[WordPress Incident Response Team](https://make.wordpress.org/project/handbook/incident-response-team/)
at `reports@wordpress.org`.

Do not open a public GitHub issue, Trac ticket, or forum topic about a sensitive
conduct report. Reporters’ privacy and safety should be protected throughout
review and enforcement.

The linked WordPress Community Code of Conduct is the complete, authoritative,
and maintained policy. This file is a repository-specific entry point, not a
replacement for that policy.
