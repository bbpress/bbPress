# Getting Support

## Start with the documentation

The [bbPress Codex](https://codex.bbpress.org/) covers installation,
configuration, themes, shortcodes, importing forums, and development topics.
Search it and the existing forum topics before opening a new discussion.

## Ask the support forums

Use the [bbPress support forums](https://bbpress.org/forums/) for installation,
configuration, theme and plugin compatibility, upgrades, imports, and
troubleshooting. Include:

- bbPress, WordPress, and PHP versions;
- the active theme and relevant plugins;
- whether the problem persists with a default, known-compatible theme and other
  plugins disabled;
- clear reproduction steps and the expected result;
- sanitized logs or screenshots when useful.

Never post passwords, authentication tokens, private user data, database
dumps, or other secrets.

Support is provided by an open-source community on a best-effort basis. The
forums are not an emergency channel and cannot provide private site access or a
guaranteed response time.

## Report a reproducible software bug

After separating a product defect from a site-specific support problem, search
[bbPress Trac](https://bbpress.trac.wordpress.org/) and open a ticket if the bug
has not already been reported. Follow [CONTRIBUTING.md](CONTRIBUTING.md) so the
report contains enough information to reproduce and test.

GitHub Issues are not the bbPress issue tracker.

## Report a vulnerability

Do not disclose vulnerabilities in a support topic, Trac ticket, or GitHub
issue. Follow [SECURITY.md](SECURITY.md) for private reporting.

## Join the contributor chat

Development discussion also happens in `#bbpress` on the
[WordPress Slack network](https://make.wordpress.org/chat/). Slack complements
Trac; decisions and patches that affect the project should remain discoverable
on the relevant Trac ticket.
